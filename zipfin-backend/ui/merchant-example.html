🛠 How this ZipRIGHT integration works

This page demonstrates the ZipRIGHT Widget SDK. Each product card has a Find My Size button injected by the SDK. The button opens a slide-up modal where the shopper enters their measurements, receives an AI size recommendation, and can launch the full ZipRIGHT Virtual Try-On experience in a new tab.

To add ZipRIGHT to your own store, paste the script tag below (once per page) and mount per-product buttons using ZipRightWidget.init():

<!-- 1. Load the SDK (once, before </body>) --> <script src="https://sdk.zipright.ai/zipright-widget.js"></script> <!-- 2. Mount a button for each product --> <script> ZipRightWidget.init({ storeUrl: "https://your-store.myshopify.com", apiBase: "https://api.zipright.ai", productId: "FIRESTORE_PRODUCT_DOC_ID", // preferred (stable) buttonTarget: "#zr-mount-container", }); </script>
